운영 로그 (실시간)

사이클: 현황 파악 → 사이트 접속 점검 → 대기 문의 답변 → 재고 점검 → 발송 확인 → 리포트 저장. 서버 창을 켜 둔 동안 설정된 주기마다 자동 반복됩니다.

판매 사이트 등록

내 상품이 올라간 페이지(Qoo10 상점, 아마존 상품페이지, 자사몰 등)의 주소를 넣으면, AI가 매 사이클마다 실제로 접속해 상태를 점검합니다.

이름URL국가최근 점검상태

ℹ️ 어떤 주소를 넣으면 되나요?

· 자사몰: https://eckasa.com (메인 또는 베스트 상품 페이지)
· Qoo10 재팬: 내 미니샵 주소 (예: https://www.qoo10.jp/shop/상점명)
· 아마존 재팬: 내 상품 상세페이지 주소
· 샤오홍슈 등: 내 브랜드/상품 페이지 주소
AI는 페이지의 글자를 읽고 접속 가능 여부, 품절 표시, 가격 이상 등을 점검해 이상하면 알림함에 등록합니다.
※ 로그인해야만 보이는 판매자센터 페이지(주문 목록 등)는 읽을 수 없어요. 그런 곳의 문의는 [운영 데이터] 탭에 붙여넣으면 AI가 답변을 만들어 둡니다.

🔔 사람 확인이 필요한 일

AI가 스스로 처리하면 안 되는 일(발주 확정, 가격 변경, 사이트 이상, 환불 승인 등)이 여기 쌓입니다. 처리하셨으면 [완료]를 누르세요.
