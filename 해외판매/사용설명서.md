## 1. 에카사-판매관리.html

### 📊 대시보드
총 주문 수, 이번 달 매출(원화 환산), 재고 부족 상품, 배송 진행 건수를 한눈에 봅니다.

### 🔗 판매 링크 — 나라별 판매 링크 설정
- 국가를 선택하고 마켓플레이스(Amazon, Shopee, Qoo10 등)와 내 상점 링크를 등록합니다.
- 국가별 추천 마켓플레이스 목록이 하단에 표시됩니다.

### 📦 재고 — 재고 현황
- 에카사 실제 제품 14종(싱글 보냉백, 토바백, 파우치 등)이 미리 등록되어 있습니다.
- 재고가 안전재고 이하로 내려가면 **빨간색 [부족]** 표시가 뜹니다.
- **주문을 "발송완료"로 바꾸면 재고가 자동으로 차감됩니다.** 입고 시 [+입고] 버튼 사용.

### 🧾 주문·결제 — 결제 방식 관리
- 주문 등록 시 결제 방식(신용카드/PayPal/Stripe/마켓 정산/COD)과 결제 상태(결제대기/완료/환불)를 기록합니다.
- 국가·결제상태별로 필터링할 수 있습니다.

### 🚚 배송 — 배송 현황 확인
- 배송사와 송장번호를 입력하면 **[추적] 버튼으로 배송사 조회 페이지가 바로 열립니다.**
- 상태: 준비중 → 발송완료 → 통관중 → 배송중 → 배달완료

### 🖨️ 라벨 출력
- 배송 탭에서 [라벨] 버튼 → 발송인/수취인 주소, **스캔 가능한 바코드(Code 39)**, 세관신고서(CN22)가 포함된 라벨이 새 창에 열립니다 → [인쇄하기] 클릭.
- ⚠️ 라벨에 인쇄될 **판매자 영문 주소를 [설정] 탭에 먼저 입력**하세요.

### 📞 배송사 연락 — 배송사 직접 컨택
- 우체국 EMS/K-Packet, DHL, FedEx, UPS, CJ대한통운의 전화·홈페이지·픽업신청 페이지로 바로 연결됩니다.
- **[픽업요청 메일]** 버튼: 발송 대기 주문 목록이 자동으로 담긴 메일 초안이 열립니다.

### 🤖 AI 상담사
- 해외 고객의 문의(영어·일본어 등 아무 언어)를 붙여넣으면, **고객 언어로 된 답변 + 한국어 번역**을 함께 만들어 줍니다.
- 에카사 제품 목록과 [설정]에 입력한 상점 정책을 알고 답변합니다.

### 🌐 자동 번역
- 해외 사이트 내용·리뷰·메시지를 붙여넣으면 한국어로 번역 → 해외 사이트 내용을 쉽게 이해할 수 있습니다.
- 한국어 → 영어/일본어/중국어 등 9개 언어 번역도 지원합니다.

### ⚙️ 설정 (처음에 꼭 하세요)
1. **Claude API 키**: AI 상담사·번역에 필요합니다.
   - https://console.anthropic.com 접속 → 가입 → API Keys에서 키 발급 → 복사해 붙여넣고 저장.
   - 키는 이 컴퓨터 브라우저에만 저장되며 외부로 전송되지 않습니다(Anthropic API 호출 제외).
   - API 사용량에 따라 소액의 요금이 발생합니다(상담 1건당 수십 원 수준).
2. **판매자 정보**: 영문 이름/주소/전화 — 배송 라벨에 인쇄됩니다.
3. **상점 정책**: 배송기간·반품 정책을 적어두면 AI 상담사가 이를 근거로 답변합니다.
4. **데이터 백업**: 모든 데이터는 브라우저에 저장되므로, 주기적으로 [백업 파일 저장]을 눌러 파일로 보관하세요. (브라우저 데이터 삭제 시 유실될 수 있음)

## 2. 에카사-시장분석.html

### 🏆 시장 매력도 순위
12개국을 시장규모·가격수용성·물류·결제·리스크 5개 항목으로 평가한 종합 순위.
**추천 진출 순서: ① 일본 → ② 대만·싱가포르 → ③ 미국·호주**

### 💰 적정가격 계산기 — 각 나라별 판매 적정 가격
제품·국가·배송방식·마진율을 선택하면:
- 원가 + 배송비 + 마켓 수수료 + 결제 수수료를 반영한 **권장 판매가(현지 통화)**
- 예상 순이익
- **현지 시장 가격대와의 비교**
를 계산해 줍니다. 환율·수수료는 직접 수정 가능합니다.

### 🌍 국가별 상세 분석
국가를 선택하면 가격대·마켓·결제·배송·관세·리스크를 한 페이지로 보여줍니다.
**[🤖 AI 심층 분석 리포트]** 버튼: 우선 출시 제품, 진입 채널, 마케팅, 90일 액션플랜이 담긴 맞춤 전략 리포트를 생성합니다. (판매관리 프로그램에 저장한 API 키를 자동으로 사용)

### 💳 결제방식 비교 — 결제 가능한 방식 분석
나라별 주요 결제수단(일본 편의점결제, 독일 후불, 베트남 COD 등)과 자사몰 판매 시 권장 PG를 정리했습니다.

### 🚚 배송방식 비교 — 가장 적합한 배송 방식 분석
K-Packet / EMS / 특송(DHL·FedEx)의 국가별 예상 비용(0.5kg 기준)·소요일·추천 방식.
에카사 제품은 대부분 500g 이하 경량이므로 **K-Packet이 기본, 고가 상품은 EMS**가 유리합니다.

### ⚠️ 리스크 비교 — 나라별 판매 리스크 분석
통관·세금, 규제(독일 포장재법, 유럽 VAT 등), 반품, 경쟁 리스크를 상/중/하 등급으로 정리했습니다.
- 특히 주의: **미국 소액면세(de minimis) 폐지(2025년)**, **유럽 VAT·포장재 등록 의무**, **베트남·태국 COD 미수취**

## 3. 에카사-일본중국-AI수출운영.html

일본·중국 수출에 필요한 **판매자 업무 전체**를 담았고, 반복 업무는 **AI 에이전트가 대신** 합니다.

### 🤖 AI 운영센터 (핵심)
버튼 하나로 AI 에이전트가 실제 업무를 수행합니다. 에이전트는 프로그램 안의 도구(재고 조회, 리스팅 저장, 문의 답변 저장, 주문 상태 변경, 가격 계산, 리포트 저장 등 11가지)를 직접 사용합니다.
- **📋 오늘 업무 한번에 처리**: 현황 점검 → 대기 문의 전부 답변 → 재고·발송 확인 → 일일 리포트 작성
- **💬 대기 문의 전체 답변**: 일본어/중국어 답변 + 한국어 번역을 자동 저장
- **🛍️ 리스팅 준비**: 일본어·중국어 상품명/설명/키워드/가격을 만들어 저장
- **📦 재고 점검·발주 제안 / 💰 가격 점검 / 📣 마케팅 콘텐츠 작성**
- 직접 지시도 가능: "토바 보냉백을 Qoo10에 올릴 준비해줘"
- ⚠️ 안전장치: 에이전트는 **이 프로그램 안의 데이터만** 수정하며, 마켓·이메일 등 외부로 자동 전송하지 않습니다. 작성된 답변·리스팅은 [복사] 버튼으로 붙여넣어 사용하세요.

### 나머지 탭
- **상품·리스팅**: 제품 14종 × 일본/중국 리스팅 관리, [AI 작성] 버튼으로 개별 생성
- **주문 / 문의·CS / 배송·통관**: 주문 관리, 문의함, 라벨(CN22)+**상업 인보이스** 인쇄, 일본 면세 기준(약 16,666엔)·중국 행우세 등 통관 가이드
- **마케팅 / 리포트**: AI가 만든 SNS 콘텐츠와 운영 리포트 보관함
- **설정**: API 키(판매관리와 공유), 환율, 운영 정책(에이전트의 업무 기준), **데모 데이터** 버튼으로 바로 체험 가능

※ 제품·재고·주문·API키는 「에카사-판매관리」와 자동으로 공유됩니다.

## 4. 에카사 자동운영 (⭐ 알아서 운영)

**`에카사-자동운영-시작.bat` 더블클릭** → 검은 창이 뜨고 브라우저에 관리 화면(http://localhost:8930)이 자동으로 열립니다. **검은 창을 켜 두는 동안** 정해진 주기(기본 1시간)마다 AI가 자동으로 운영 사이클을 돕니다.

### 사용법 (딱 2가지만 하면 됩니다)
1. **[설정]** 탭에서 Claude API 키 저장
2. **[판매 사이트]** 탭에서 내 판매 페이지 주소 등록 (에카사 공식몰은 예시로 미리 등록해 두었습니다)
   - 예: Qoo10 미니샵 주소, 아마존 상품페이지, eckasa.com

### 매 사이클마다 AI가 자동으로 하는 일
1. 등록된 판매 사이트에 **실제로 접속해 페이지를 읽고** 이상 점검 (접속불가·품절표시·가격이상)
2. 답변 대기 중인 고객 문의에 답변 작성 (현지어 + 한국어 번역)
3. 재고 부족 확인 → 발주 제안
4. 결제완료인데 발송 안 된 주문 확인
5. 사이클 리포트 작성 → [운영 데이터] 탭에 저장
6. **사람이 결정해야 할 일은 [승인·알림함]에 등록** (발주 확정, 가격 변경, 사이트 이상, 환불 등)

### 알아두세요
- AI는 **외부로 아무것도 자동 전송하지 않습니다.** 답변·리스팅은 만들어 두기만 하고, 실제 게시/발송은 [복사] 버튼으로 사장님이 확정합니다. (실수 방지 안전장치)
- 로그인해야 보이는 판매자센터 내부(주문목록 등)는 읽을 수 없습니다. 마켓에서 받은 문의는 [운영 데이터] 탭에 붙여넣어 두면 다음 사이클에 자동 답변됩니다. 마켓 API(Qoo10 QAPI 등) 키를 발급받으면 주문 자동 수집 연동도 추가할 수 있습니다.
- 데이터는 `자동운영\data\store.json`에 저장됩니다 (HTML 프로그램들과는 별도 저장소).
- 컴퓨터를 켤 때 자동 시작하고 싶으면: `Win+R` → `shell:startup` 입력 → 열린 폴더에 `에카사-자동운영-시작.bat`의 바로가기를 넣으세요.

## 자주 묻는 질문

**Q. 데이터는 어디에 저장되나요?**
브라우저(localStorage)에 저장됩니다. 같은 컴퓨터·같은 브라우저에서 열면 데이터가 유지됩니다. 다른 컴퓨터로 옮기려면 [설정 → 백업 파일 저장] 후 새 컴퓨터에서 [백업 불러오기] 하세요.

**Q. AI 기능이 "API 키가 올바르지 않습니다"라고 해요.**
설정 탭에서 키를 다시 확인하세요. 키는 `sk-ant-`로 시작해야 하며, console.anthropic.com에서 결제 수단(크레딧)이 등록되어 있어야 합니다.

**Q. 시장분석의 배송비·관세 숫자는 정확한가요?**
2026년 중반 기준 추정치입니다. 실제 발송 전 우체국 EMS 요금표(ems.epost.go.kr)와 각국 세관 규정을 반드시 확인하세요. 프로그램 안의 링크로 바로 이동할 수 있습니다.
