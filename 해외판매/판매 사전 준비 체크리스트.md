# 에카사 해외판매 사전 준비 체크리스트

이 프로그램들(판매관리 · 시장분석 · 일본중국 AI수출운영 · 자동운영)로 실제 판매를 시작하기 전에
**사장님이 직접 준비해야 하는 것들**을 순서대로 정리했습니다.
프로그램이 대신 못 해주는 것(계정 개설, 신고, 계약)이 무엇인지 기준으로 나눴습니다.

> ✅ = 한 번만 하면 됨 / 🔁 = 주기적으로 필요

---

## 1단계. 프로그램 기본 설정 (30분)

| 체크 | 항목 | 방법 |
|---|---|---|
| ☐ ✅ | **Claude API 키 발급** | https://console.anthropic.com 가입 → 결제수단 등록(크레딧 충전) → API Keys에서 키 생성 → 각 프로그램 [설정]에 저장. AI 상담·번역·자동운영에 필수. 사용량 과금(문의 답변 1건당 수십~수백 원 수준) |
| ☐ ✅ | **판매자 정보 입력** | 판매관리 [설정]: 영문 상호(ECKASA), 영문 주소, 전화, 이메일 — 배송 라벨·인보이스에 그대로 인쇄됨 |
| ☐ ✅ | **상점 정책 정하기** | 발송 기한(예: 2영업일), 반품 규정(기간·배송비 부담), 교환 규정, 기본 마진율 → [설정]의 정책란에 입력. AI가 이 기준으로 고객에게 답변함 |
| ☐ ✅ | **원가 확인** | 제품별 실제 원가(제조/사입가)를 정리 — 가격 계산기가 정확해짐 (미입력 시 국내판매가의 50%로 가정) |
| ☐ ✅ | **재고 수량 맞추기** | 판매관리 [재고] 탭의 수량을 실제 창고 수량과 일치시키기 (기본값 50개는 예시) |
| ☐ 🔁 | **환율 업데이트** | 시장분석·수출운영 [설정]에서 환율 확인 (월 1회 정도) |
| ☐ 🔁 | **데이터 백업** | [설정 → 백업 파일 저장] 주 1회 권장 |

## 2단계. 사업·법무 준비 (1~2주)

| 체크 | 항목 | 설명 |
|---|---|---|
| ☐ ✅ | **사업자등록** | 이미 있으시면 통과. 업태에 '전자상거래업/도소매' 포함 확인 |
| ☐ ✅ | **통신판매업 신고** | 관할 지자체(정부24에서 온라인 가능) — 국내 판매용이지만 해외 마켓 가입 때도 요구되는 경우 있음 |
| ☐ ✅ | **해외 정산 계좌** | 마켓 판매대금 수령용: **PayPal 비즈니스** 또는 **Payoneer**(Qoo10·아마존 정산에 널리 사용) 계정 개설 |
| ☐ ✅ | **상표권 확인·출원** | ⚠️ 특히 중요: 한국 상표 + **일본(JPO)·중국(CNIPA) 상표 출원**. 중국은 상표 선점(브로커가 먼저 등록) 피해가 흔하므로 판매 시작 전 출원 권장. 특허사무소 통해 국가당 수십만 원대 |
| ☐ ✅ | **세무 확인** | 수출 매출은 영세율 적용 가능 — 세무사에게 "해외 직판(B2C) 영세율·구매확인서" 문의 |

## 3단계. 일본 판매 준비 (1~2주)

| 체크 | 항목 | 설명 |
|---|---|---|
| ☐ ✅ | **Qoo10 재팬 셀러 가입** | https://www.qoo10.jp → 판매자(QSM) 가입. 준비물: 사업자등록증, 대표 신분증, 정산 계좌(Payoneer 등). 가입비 무료 — 첫 진입 추천 채널 |
| ☐ ✅ | (선택) **Amazon JP 셀러** | 월 4,900엔 프로페셔널 플랜 + KYC 심사. Qoo10에서 매출 검증 후 확장 권장 |
| ☐ ✅ | **상품 사진 준비** | 흰 배경 정면컷 + 연출컷(피크닉·도시락 활용 장면) 제품당 5~8장. 일본은 사이즈 표기(cm)와 디테일컷 중시 |
| ☐ ✅ | **일본어 리스팅 만들기** | → 프로그램이 해줍니다: 수출운영 [상품·리스팅]에서 [AI 작성] 또는 AI 운영센터 [리스팅 준비] 버튼 → 생성된 상품명·설명·키워드를 복사해 마켓에 등록 |
| ☐ 🔁 | **가격 결정** | 시장분석 [적정가격 계산기] 결과 + 현지 시세 비교로 확정 (예: 토바 보냉백 ¥6,390~6,490) |

## 4단계. 중국 판매 준비 (전략적으로 천천히)

| 체크 | 항목 | 설명 |
|---|---|---|
| ☐ ✅ | **진입 방식 결정** | 직접 입점(티몰글로벌)은 보증금·연회비 부담 大 → 초기에는 ①구매대행 입점 ②샤오홍슈 콘텐츠+대행 판매 권장 |
| ☐ ✅ | **샤오홍슈 계정** | 브랜드 노트(제품 사진+감성 글) 축적 — 프로그램의 [마케팅] AI가 중국어 노트 초안을 만들어 줌 |
| ☐ ✅ | **상표 중국 출원** | 2단계와 중복이지만 중국은 특히 판매 노출 전에 출원할 것 |
| ☐ 🔁 | **위조품 모니터링** | 자동운영에 타오바오 검색결과 페이지를 사이트로 등록해 두면 주기 점검에 활용 가능 |

## 5단계. 물류·배송 준비 (3~5일)

| 체크 | 항목 | 설명 |
|---|---|---|
| ☐ ✅ | **우체국 계약 상담** | 관할 우체국 또는 1588-1300: 사업자 **EMS 계약요금**(할인) + **K-Packet 계약**(2kg 이하 경량 최저가, 계약해야 이용 가능) + 방문수거 신청 방법 확인 |
| ☐ ✅ | **포장재 구매** | 폴리백/에어캡/박스(경량 위주 — 무게가 곧 배송비), 테이프, 지퍼백. 보냉백은 눌림 방지 형태 유지 포장 |
| ☐ ✅ | **저울(1g 단위)** | 배송비 계산·세관신고 무게 기재용 |
| ☐ ✅ | **프린터 확인** | A4 프린터면 충분 — 프로그램의 [라벨]·[인보이스] 출력용 |
| ☐ ✅ | **HS코드 확인** | 가방류 4202.92 등 — 관세사 또는 우체국 창구에서 품목별 1회 확인 |
| ☐ 🔁 | **발송 루틴** | 주문 확인 → 프로그램에서 라벨+인보이스 출력 → 포장 → 방문수거/접수 → 송장번호 입력(재고 자동 차감) |

## 6단계. 자동운영 가동 (10분)

| 체크 | 항목 | 설명 |
|---|---|---|
| ☐ ✅ | **자동운영 시작** | `에카사-자동운영-시작.bat` 더블클릭 → [설정] API 키 저장 → [판매 사이트]에 내 Qoo10 미니샵·상품페이지 URL 등록 |
| ☐ ✅ | (선택) **부팅 시 자동 시작** | `Win+R` → `shell:startup` → 열린 폴더에 bat 바로가기 넣기 |
| ☐ 🔁 | **하루 1번 확인** | [승인·알림함]에 쌓인 항목(발주 제안, 사이트 이상, 발송 요청)만 확인·처리 — 나머지는 AI가 해 둠 |
| ☐ 🔁 | **문의 넣어주기** | 마켓 판매자센터에서 온 문의를 [운영 데이터] 탭에 붙여넣기 → 다음 사이클에 자동 답변 생성 |

## 한눈에 보는 시작 순서 (추천 타임라인)

```
1주차  : 프로그램 설정 + API 키 + 상표 출원 의뢰 + Payoneer 개설
2주차  : Qoo10 재팬 셀러 가입 + 우체국 EMS/K-Packet 계약 + 사진 촬영
3주차  : AI로 일본어 리스팅 생성 → Qoo10 등록 (보냉백 3종부터) + 자동운영 가동
4주차~ : 첫 주문 처리(라벨·인보이스 출력 → 발송) + 샤오홍슈 콘텐츠 시작
        일본 매출 안정화 후 → Amazon JP → 중국 본격 진입 순서로 확장
```

## 예산 가늠 (대략)

| 항목 | 대략 비용 |
|---|---|
| Claude API 사용료 | 월 1~3만 원 수준 (자동운영 주기·사용량에 따라) |
| 상표 출원 (일본+중국) | 국가당 약 30~80만 원 (사무소별 상이) |
| Qoo10 가입 | 무료 (판매 수수료 약 10%) |
| Amazon JP (선택) | 월 4,900엔 |
| 포장재·저울 초기 구입 | 10~20만 원 |
| 우체국 계약 | 무료 (요금 후불) |
